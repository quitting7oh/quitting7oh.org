## Start with vitamin C

If your quit is planned, start the liposomal vitamin C preload before your last 7-OH dose. If withdrawal has started, skip the preload and begin with the acute schedule. [Read the full vitamin C guide](/medications-supplements/mega-dose-vitamin-c) before using high doses.
